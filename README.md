# Prime Video Dashboard

# `Overview`

This project is a Power BI dashboard that provides insights into the data of Prime Video's content library. It showcases key metrics like total titles, genres, ratings, countries, and release years, offering a comprehensive view of the platform's offerings. The dashboard is visually designed to support data-driven decisions and analysis.

`Features`

* Total Titles: Displays the overall count of available titles.

* Total Ratings: Highlights the number of unique ratings.

* Total Genres: Shows the variety of genres.

* Total Directors: Counts the total number of directors associated with the titles.

* Timeline: Provides the start and end years of the data range (1920 to 2021).

* Rating Distribution: Visualizes the count of titles for each rating category (e.g., TV-PG, PG-13).

* Genre Analysis: Highlights the number of shows per genre.

* Country-wise Distribution: Maps the total number of shows by country.

* Movies vs TV Shows: Displays the proportion of movies and TV shows in a pie chart.

* Release Year Distribution: Shows the count of titles released over the years.

`Tools Used`

* Power BI: Used for data visualization and dashboard creation.

* Data Source: The dataset used for this dashboard includes Prime Video’s content metadata.
